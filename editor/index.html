NES CHR Editor — help

  • Paint on the 8×8 grid with the left mouse button. Right-click (or right-drag) erases back to color 0.
  • Pick a paint color: click one of the 4 slots (keys 1–4), then click any swatch in the 64-color NES master palette to assign it.
  • Sub-palettes: choose one of the 4 slots of the BG or SPR set; the sprite preview always uses the current sub-palette.
  • CHR format: 256 tiles × 16 bytes = 4096 bytes. Each tile is 8 bytes of bit-plane 0 followed by 8 bytes of bit-plane 1, bit 7 = leftmost pixel.
  • Export .chr.inc with the ↓ .chr.inc button — it emits .byte lines in this project's assembler syntax.
